# Sessoes

Use esta pasta apenas para registros curtos de trabalhos relevantes futuros.

Formato sugerido:

- um arquivo por marco importante;
- nome `AAAA-MM-DD-resumo-curto.md`;
- 5 a 10 linhas no maximo;
- links para documentos do brain quando houver mudanca duradoura.

Nao registrar logs extensos, credenciais, dados pessoais ou transcricoes completas.
